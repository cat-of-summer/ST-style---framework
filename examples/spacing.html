Отступы — m · mt · mb · p · pt · pb

Вертикальные margin/padding задаются числом-множителем шкалы --space-step (по умолчанию 0.4rem — 4px на эталонной ширине брейкпоинта). Формула: N × var(--space-step). Всё ниже управляется только атрибутами. Полосатый фон вокруг блока показывает margin, голубая рамка вокруг синей плашки — padding.

Фреймворк управляет только вертикальными отступами (top/bottom). Горизонтальные (left/right) задаются в компонентных CSS. Значения — числа 0–25 для margin/padding на каждом брейкпоинте.
шкалаmt / mbm (оба) p / pt / pbпо брейкпоинтам--space-step

1 · Шкала N × 0.4rem

mt="0" → 0
mt="1" → 0.4rem
mt="2" → 0.8rem
mt="4" → 1.6rem
mt="6" → 2.4rem
mt="10" → 4rem
<div mt="1">0.4rem</div>
<div mt="2">0.8rem</div>
<div mt="4">1.6rem</div>
<div mt="6">2.4rem</div>
<div mt="10">4rem</div>

Каждый плашка отделена от предыдущей своим margin-top. Полосатый фон между ними — это и есть margin (растёт кратно 0.4rem).

2 · mt / mb — верх / низ

mt="6" (2.4rem сверху)
mt="6"
mb="6" (2.4rem снизу)
mb="6"
<section mt="6">margin-top: 2.4rem</section>
<div mb="12">margin-bottom: 4.8rem</div>

mt → margin-top, mb → margin-bottom. Хранят число в --mt/--mb, applier домножает на --space-step.

3 · m — сверху и снизу сразу

соседний блок
m="5" → 2rem сверху и снизу
соседний блок
<article m="5">margin-top: 2rem + margin-bottom: 2rem</article>

m="N" ставит одинаковый вертикальный margin сверху и снизу. Полосатые зоны над и под средней плашкой — оба отступа.

4 · p / pt / pb — внутренние

p="5" (2rem внутри, сверху+снизу)
контент
pt="8" (3.2rem только сверху)
контент
pb="8" (3.2rem только снизу)
контент
<button p="5">padding по вертикали 2rem</button>
<div pt="4 lg-8">padding-top 1.6rem → 3.2rem на lg</div>
<div pb="4">padding-bottom 1.6rem</div>

Голубой фон вокруг синей плашки «контент» — это padding. p — сверху и снизу, pt/pb — по отдельности.

5 · По брейкпоинтам (mobile-first)

Тяни ширину окна — отступ переключается. Несколько значений через пробел; последний подходящий брейкпоинт выигрывает.

якорь
mt="2 lg-10" → 0.8rem, а с lg (≥1280px) 4rem
якорь
якорь
mt="4 md-8 lg-12" → 1.6 → 3.2 (md) → 4.8rem (lg)
якорь
<section mt="3 lg-6">   <!-- 1.2rem везде, 2.4rem на lg+ -->
<div mb="4 md-8 lg-12"> <!-- 1.6rem → 3.2rem (md) → 4.8rem (lg) -->
<div mt="xs-3">        <!-- 1.2rem начиная с ≥360px -->

Префиксы: xs (≥360) · sm (≥576) · md (≥768) · lp (≥1024) · lg (≥1280) · dt (≥1536) · xl (≥1920). Безпрефиксное значение действует с ≥0px.

6 · Рантайм-множитель --space-step

Все утилиты считаются как calc(N × var(--space-step)). Переопредели --space-step на обёртке — и весь блок отступов перемасштабируется одним значением.

по умолчанию: 0.4rem → p="5" = 2rem
--space-step: 0.4rem
--space-step: 0.8rem → p="5" = 4rem
--space-step: 0.8rem
<div style="--space-step: 0.8rem">
    <p p="5">5 × 0.8rem = 4rem</p>
</div>
Шаг задан в rem, поэтому отступы масштабируются вместе с html { font-size: …vw }: внутри брейкпоинта пропорции отступов и шрифта не меняются. Подробнее о шкале — в typography.

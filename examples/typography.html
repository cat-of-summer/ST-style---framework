Типографика — rem · tx · fw · lc

Все размеры — в rem, а font-size у html задан в vw на каждом брейкпоинте. Меняй ширину окна — в шапке видно активный брейкпоинт, чему сейчас равен 1rem и вычисленный размер образцового h1. Отступы — в spacing.

Модель: на брейкпоинте html { font-size: font / design × 100vw }, то есть на эталонной ширине design (по умолчанию = min брейкпоинта) 1rem = font (по умолчанию 10px). Внутри брейкпоинта всё растёт пропорционально ширине, на границе — скачок к шкале следующего.

1 · Шкала html { font-size: …vw }

На нижней границе брейкпоинта 1rem = 10px, к верхней растёт пропорционально ширине. Тяни ширину окна: внутри брейкпоинта h1 в шапке меняется плавно, на границе брейкпоинта — прыгает обратно к 10px × 3.2.

2 · Один брейкпоинт — одна картинка

Карточка свёрстана целиком в rem (ширина 28rem, картинка 12rem, отступы 1.6rem). Внутри брейкпоинта она выглядит одинаково на любой ширине — просто крупнее или мельче, пропорции и переносы строк не меняются.

Заголовок карточки

Текст карточки. Переносы строк остаются теми же при любой ширине окна в пределах брейкпоинта.

3 · Настройка под свой макет

Всё задаётся в $breakpoints и $font-sizes. На каждый брейкпоинт — min (порог), design (ширина макета, необязательно, по умолчанию = min), font (1rem на этой ширине, необязательно, по умолчанию 10px).

@use '@cat-of-summer/st-style/scss/main/config' with (
  $breakpoints: (
    xs: (min: 360px,  design: 375px,  container: 343px),
    md: (min: 768px,  container: 720px),
    lg: (min: 1280px, design: 1440px, font: 12px, container: 1320px),
  ),
  $font-sizes: (h1: 4rem, h2: 3rem, h3: 2.4rem, h4: 2rem, h5: 1.8rem, h6: 1.6rem, p: 1.4rem),
);
@use '@cat-of-summer/st-style/scss/main';

Без пересборки — обычным CSS: размеры токенов через :root { --fs-h1: 4rem }, шкалу через правило на html.

4 · tx — именованный размер на любом элементе

span tx="h1"
span tx="h3" · tx="h5" · tx="p"
div, но выглядит как H2 (tx="h2")
<p tx="h2">Крупный текст</p>
<span tx="h5">Маленький заголовок</span>
<div tx="p">Обычный текст</div>
<button tx="h4">Кнопка</button>

Ставит font-size из токена --fs-* (с !important) на любой тег — семантика не меняется. Значения h1…h6, p и кастомные ключи из $font-sizes.

5 · Кастомные токены размера

Hero (--fs-hero)

Лид-абзац (--fs-lead, 1.8rem).

Слегка увеличенный p1 (--fs-p1, 1.4rem) — напрямую через font-size.

:root { --fs-lead: 1.8rem; }

<p tx style="--tx: var(--fs-lead)">лид</p>
<p style="font-size: var(--fs-lead)">лид</p>   <!-- то же самое -->

Токены — обычные длины в rem, их можно подставлять куда угодно. Для частых токенов — ключ в карту $font-sizes, тогда появится и tx="lead".

6 · fw — вес шрифта

thin (100)

light (300)

normal (400)

semibold (600)

bold (700)

black (900)

<h3 fw="light">Лёгкий заголовок</h3>
<span fw="extrabold">Жирный текст</span>
<p fw="normal">Обычный текст</p>

Устанавливает font-weight с !important на любой элемент. Значения: thin · extralight · light · normal · medium · semibold · bold · extrabold · black (100…900).

7 · lc — ограничение строк (line-clamp)

lc="2"

Длинный текст, который будет обрезан после второй строки многоточием. Здесь много слов, чтобы гарантированно получить перенос и увидеть обрезку в действии на любой ширине колонки.

lc="3 lg-0"

3 строки на мобиле/планшете, а на lg (≥1280px) ограничение снимается и текст показывается целиком. Здесь тоже добавлено достаточно слов для нескольких строк переноса и наглядности.

<p lc="2">обрезать после 2 строк</p>
<p lc="3 lg-0">3 строки, на lg+ ограничение снято (0)</p>
<p lc="4 md-0 lg-10">4 → выкл → 10</p>

Обрезает текст многоточием; поддерживает брейкпоинты. Числа 1–10, 0 = выключить.

8 · Reset-типографика (автоматически)

h1–h6 без атрибута — жадный перенос, как в Figma

Достаточно длинный заголовок, чтобы увидеть балансировку переносов по строкам

[balance] — строки выровнены по длине

Достаточно длинный заголовок, чтобы увидеть балансировку переносов по строкам

text-wrap: pretty (p) — нет висячих строк

Абзац с включённым pretty: последняя строка не остаётся с одним «висячим» словом, а перенос распределяется аккуратнее по всему блоку текста.

hyphens: auto (нужен lang на <html>)

Переносослияниепереносослияние — узкая колонка демонстрирует переносы по слогам.

<!-- применяется автоматически reset'ом, без атрибутов -->
<p>...</p>    /* text-wrap: pretty; hyphens: auto */
<html lang="ru"> <!-- нужен для hyphens -->
<!-- баланс строк — по атрибуту -->
<h2 balance>...</h2>  /* text-wrap: balance */

Правила из CSS Reset применяются к p без атрибутов; balance включается вручную на любом элементе. Полный список reset — в документации.
